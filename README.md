BlogSpace 📝

BlogSpace is a dynamic blogging web application where users can create, share, and explore blog posts in one place. It provides a user-friendly platform for expressing ideas, sharing knowledge, and connecting with content through an interactive interface.

Features

🔐 User Authentication and Login

✍️ Create, Read, and Manage Blog Posts

👤 User Profiles

❤️ Like and Interact with Posts

📱 Responsive User Interface

🗄️ MongoDB Database Integration

Tech Stack

Frontend: HTML, CSS, JavaScript, EJS

Backend: Node.js, Express.js

Database: MongoDB, Mongoose

Authentication: Express Sessions / Password Hashing with bcrypt

BlogSpace is built to provide a simple and engaging blogging experience while demonstrating full-stack web development skills.
